FACE RECOGNITION ATTENDANCE SYSTEM - QUICK START GUIDE
================================================================================

STEP 1: INSTALL DEPENDENCIES
-----------------------------
Open Command Prompt in project folder and run:

    pip install -r requirements.txt

Note: Installation may take 10-30 minutes on old hardware.


STEP 2: BUILD FACE ENCODINGS
-----------------------------
The dataset with 8 employees is ALREADY INCLUDED in the project folder:

    FaceAttendanceSystem/dataset/

Employees included:
- Ali (34 photos)
- Amirreza (30 photos)
- Benyamin (30 photos)
- Hamidreza (34 photos)
- Kian (30 photos)
- Mahdi (36 photos)
- Mohammad (32 photos)
- Mojtaba (31 photos)

Run this command to build face encodings:

    python build_embeddings.py

Or double-click: build_encodings.bat

This will process all 257 photos and create face encodings.


STEP 3: RUN APPLICATION
-----------------------
Start the application:

    python app.py

Or double-click: run_app.bat

The main window will appear with CHECK IN and CHECK OUT buttons.


USAGE:
------
1. Click CHECK IN or CHECK OUT
2. Webcam opens automatically
3. Employee stands 50-120 cm from camera
4. Face is recognized automatically (2-5 seconds)
5. Attendance saved to database
6. Success message displayed
7. Return to main menu


ADDING NEW EMPLOYEES:
---------------------
1. Create new folder in dataset/ with employee name
2. Add 3-5 photos (JPG, PNG, BMP)
3. Run: python build_embeddings.py
4. Done!


PORTABLE PROJECT:
-----------------
This project is completely self-contained!

✓ Dataset INCLUDED in project folder
✓ All code included
✓ No external dependencies

To use on another computer:
1. Copy entire FaceAttendanceSystem folder
2. Install Python and dependencies
3. Run build_embeddings.py
4. Run app.py


TROUBLESHOOTING:
----------------
Problem: pip install fails
Solution: Install Visual C++ Build Tools and CMake first
         See INSTALLATION.txt for details

Problem: Camera not opening
Solution: Check USB connection
         Try different CAMERA_ID in config.py (0, 1, 2...)

Problem: Recognition too slow
Solution: Increase FRAME_SKIP to 3 or 4 in config.py
         Or lower camera resolution

Problem: Poor recognition accuracy
Solution: Add more photos per employee
         Adjust RECOGNITION_TOLERANCE in config.py
         Ensure good lighting
