CONFIGURATION OPTIONS:
======================

Edit config.py to adjust:

Camera Settings:

- CAMERA_WIDTH = 640
- CAMERA_HEIGHT = 480
- FALLBACK_WIDTH = 320
- FALLBACK_HEIGHT = 240

Recognition Settings:
- RECOGNITION_TOLERANCE = 0.6 (lower = stricter)
- FRAME_SKIP = 2 (higher = faster but less responsive)
- RECOGNITION_TIMEOUT = 15 (seconds)

All settings work without code changes!


TROUBLESHOOTING:
================

Problem: pip install fails
Solution: Install Visual C++ Build Tools and CMake first
         See INSTALLATION.txt for details

Problem: Camera not opening
Solution: Check USB connection
         Try different CAMERA_ID in config.py (0, 1, 2...)

Problem: No face encodings found
Solution: Run build_embeddings.py first

Problem: Recognition too slow
Solution: Increase FRAME_SKIP to 3 or 4 in config.py
         Or lower camera resolution

Problem: Poor recognition accuracy
Solution: Add more photos per employee
         Adjust RECOGNITION_TOLERANCE in config.py
         Ensure good lighting

Problem: Unknown employee detected
Solution: Rebuild encodings: python build_embeddings.py
         Check if employee photos exist in dataset
         Adjust RECOGNITION_TOLERANCE
