FACE RECOGNITION ATTENDANCE SYSTEM - PROJECT INFORMATION
================================================================================

PROJECT OVERVIEW:
-----------------
A production-ready face recognition attendance system optimized for low-end
hardware (Windows 7, 2GB RAM, old CPU, no GPU). The system uses face
recognition to automatically track employee check-in and check-out times.


OPTIMIZATION FOR OLD HARDWARE:
------------------------------
- HOG face detection (not CNN) - much faster
- Frame skipping - process every 2nd or 3rd frame
- Low resolution support (640x480 or 320x240)
- Minimal memory usage
- Single face recognition per session
- Lightweight dependencies only


TECHNOLOGY STACK:
-----------------
- Python 3.7-3.9
- OpenCV - Computer vision
- face_recognition - Face recognition
- dlib - Face detection (HOG model)
- SQLite - Database
- Tkinter - User interface
- pickle - Serialization


KEY FEATURES:
-------------
1. Simple UI with CHECK IN/CHECK OUT buttons
2. Automatic face recognition (50-120 cm distance)
3. SQLite database for attendance records
4. Comprehensive logging system
5. Easy configuration without code changes
6. Add new employees without code modifications
7. Export attendance to CSV
8. System diagnostics utility

APPLICATION FLOW:
-----------------
1. Launch app.py
2. Main window appears
3. Operator selects CHECK IN or CHECK OUT
4. Webcam opens automatically
5. Employee stands in front of camera (50-120 cm)
6. Face is detected and recognized
7. Attendance saved to database
8. Success message displayed
9. Webcam closes automatically
10. Return to main menu


DATABASE SCHEMA:
----------------
Table: attendance

Columns:
- id (INTEGER PRIMARY KEY)
- employee_id (TEXT)
- employee_name (TEXT)
- check_type (TEXT) - "CHECK IN" or "CHECK OUT"
- date (TEXT) - YYYY-MM-DD
- time (TEXT) - HH:MM:SS
- confidence (REAL) - 0.0 to 1.0
- camera_id (INTEGER)
- timestamp (DATETIME)


CONFIGURATION OPTIONS:
----------------------
All settings in config.py:

Camera:
- CAMERA_ID (0 = default webcam)
- CAMERA_WIDTH, CAMERA_HEIGHT (resolution)
- FALLBACK_WIDTH, FALLBACK_HEIGHT (fallback resolution)

Recognition:
- RECOGNITION_MODEL ("hog" only for speed)
- RECOGNITION_TOLERANCE (0.6 = default, lower = stricter)
- FACE_DETECTION_UPSAMPLE (0 = fastest)
- FRAME_SKIP (2 = every 2nd frame)

Timeout:
- RECOGNITION_TIMEOUT (15 seconds default)

UI:
- ORGANIZATION_NAME
- WINDOW_WIDTH, WINDOW_HEIGHT

Paths:
- DATASET_PATH
- ENCODINGS_PATH
- DATABASE_PATH
- LOG_PATH


PERFORMANCE TUNING:
-------------------
For slower systems:
- Increase FRAME_SKIP to 3 or 4
- Lower camera resolution to 320x240
- Ensure FACE_DETECTION_UPSAMPLE = 0
- Close other applications

For better accuracy:
- Use higher resolution (640x480)
- Decrease RECOGNITION_TOLERANCE to 0.5
- Add more training photos per employee
- Ensure good lighting


ADDING NEW EMPLOYEES:
---------------------
1. Create folder: dataset/New_Employee_Name/
2. Add 3-5 clear photos (JPG/PNG)
3. Run: python build_embeddings.py
4. Done - no code changes needed

TROUBLESHOOTING:
----------------
See README.md for detailed troubleshooting guide

Common issues:
- Camera not opening: Check USB connection, try different CAMERA_ID
- Slow performance: Increase FRAME_SKIP, lower resolution
- Poor accuracy: Add more photos, adjust RECOGNITION_TOLERANCE
- Import errors: Install dependencies with pip
