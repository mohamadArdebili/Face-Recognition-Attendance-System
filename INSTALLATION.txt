================================================================================
FACE RECOGNITION ATTENDANCE SYSTEM - INSTALLATION GUIDE
================================================================================

SYSTEM REQUIREMENTS:
--------------------
- Windows 7 or higher
- 2GB RAM minimum
- Python 3.7, 3.8, or 3.9
- USB Webcam
- Internet connection (for installation only)


INSTALLATION STEPS:
===================

STEP 1: INSTALL PYTHON
-----------------------
1. Download Python 3.7, 3.8, or 3.9 from:
   https://www.python.org/downloads/

2. Run the installer

3. IMPORTANT: Check "Add Python to PATH" during installation

4. Verify installation:
   Open Command Prompt and type:
   python --version

   Should show: Python 3.7.x, 3.8.x, or 3.9.x


STEP 2: INSTALL VISUAL C++ BUILD TOOLS
---------------------------------------
Required for dlib installation.

1. Download from:
   https://visualstudio.microsoft.com/visual-cpp-build-tools/

2. Run the installer

3. Select "Desktop development with C++" workload

4. Click Install (may take 30-60 minutes)


STEP 3: INSTALL CMAKE
----------------------
Required for dlib installation.

1. Download from:
   https://cmake.org/download/

2. Run the installer

3. IMPORTANT: Check "Add CMake to system PATH" during installation

4. Verify installation:
   Open Command Prompt and type:
   cmake --version


STEP 4: INSTALL PYTHON DEPENDENCIES
------------------------------------
1. Open Command Prompt

2. Navigate to project folder:
   cd Desktop\FaceAttendanceSystem

3. Install dependencies:
   pip install -r requirements.txt

   Note: This may take 10-30 minutes on old hardware.
   The dlib package is large and takes time to compile.

4. If dlib installation fails, try:
   pip install dlib-binary


STEP 5: VERIFY INSTALLATION
----------------------------
Test if all packages are installed:

python -c "import cv2, face_recognition, pickle; print('All packages OK!')"

Should print: All packages OK!


STEP 6: SETUP DATASET
---------------------
1. Create dataset folder at:
   ~/Desktop/face_detection/dataset

   On Windows:
   C:\Users\YourUsername\Desktop\face_detection\dataset

2. Create one folder per employee:
   dataset\Employee_Name_1\
   dataset\Employee_Name_2\
   etc.

3. Add 3-5 clear photos per employee folder

4. Photo requirements:
   - Format: JPG, PNG, or BMP
   - Quality: Clear, well-lit
   - Face: Clearly visible
   - One person per photo


STEP 7: BUILD FACE ENCODINGS
-----------------------------
1. Double-click: build_encodings.bat

   OR

   Open Command Prompt and run:
   python build_embeddings.py

2. Wait for completion

3. Should see:
   "Build Complete!"
   "You can now run: python app.py"


STEP 8: RUN APPLICATION
-----------------------
1. Double-click: run_app.bat

   OR

   Open Command Prompt and run:
   python app.py

2. Main window should appear

3. Click CHECK IN or CHECK OUT to test


COMMON INSTALLATION ISSUES:
===========================

Issue: pip is not recognized
Solution: 
- Reinstall Python and check "Add Python to PATH"
- Or use: python -m pip install -r requirements.txt

Issue: dlib installation fails
Solution:
- Install Visual C++ Build Tools
- Install CMake
- Try: pip install dlib-binary
- Or download pre-compiled wheel from:
  https://github.com/sachadee/Dlib

Issue: face_recognition import error
Solution:
- Install dlib first
- Then: pip install face-recognition

Issue: CMake not found during dlib install
Solution:
- Install CMake from cmake.org
- Add to PATH
- Restart Command Prompt

Issue: Microsoft Visual C++ 14.0 required
Solution:
- Install Visual C++ Build Tools
- Select "Desktop development with C++" workload

Issue: No module named 'cv2'
Solution:
- pip install opencv-python

Issue: Import error on Windows 7
Solution:
- Use Python 3.7 or 3.8 (not 3.10+)
- Update pip: python -m pip install --upgrade pip
