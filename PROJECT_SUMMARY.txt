USAGE WORKFLOW:
===============

1. Operator launches application (run_app.bat)
2. Main window displays with current date/time
3. Employee approaches camera position
4. Operator clicks CHECK IN or CHECK OUT
5. Webcam opens automatically
6. Employee stands 50-120 cm from camera
7. System detects and recognizes face (2-5 seconds)
8. Attendance automatically saved to database
9. Success message displays:
   - Employee name
   - Check type
   - Date and time
   - Confidence score
10. Webcam closes automatically
11. Return to main menu
12. Ready for next employee

Average time per employee: 10-15 seconds
